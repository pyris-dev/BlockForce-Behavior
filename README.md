# BlockForce Behavior

BlockForce adds a physics gun to Minecraft Bedrock, letting you pick up blocks
and entities, move them through the air, and launch them across the world.

## Using the physics gun

- Aim at a block or entity and use the gun to pick it up.
- Look around to move what you're holding.
- Use the gun again to release it, or hit an entity with the gun to launch it.
- Switch away from the gun to release what you're holding.

Blocks appear as floating blocks while held and are placed back into the world
when released. Launched objects follow an arc and react to block collisions.
